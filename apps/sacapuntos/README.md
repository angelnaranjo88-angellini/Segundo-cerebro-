# Sacapuntos — panel de lealtad

Prototipo de una sola página. Se abre directo en el navegador: no tiene build, ni
dependencias, ni backend. Todo el estado vive en memoria y se pierde al recargar.

- `dashboard.html` — la pantalla principal completa (v1).

Datos, clientes y cifras son de ejemplo. Documentación y decisiones abiertas en
`wiki/proyectos/Sacapuntos-Lealtad-Papeleria.md`.
