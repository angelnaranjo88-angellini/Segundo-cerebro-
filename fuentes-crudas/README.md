# Fuentes crudas

Documentos **inmutables** que tú aportas: artículos, PDFs, capturas, exportaciones de blueprints
de Make, transcripciones, hojas de cálculo, briefs de cliente.

Reglas:

- El LLM **lee pero nunca modifica ni borra** nada de esta carpeta.
- Un archivo por fuente. Nombre con fecha al frente: `2026-09-05-brief-cut-inscripciones.pdf`.
- Cada fuente ingerida obtiene su resumen en `wiki/fuentes/`, no aquí.
- **Sin secretos**: nada de tokens, API keys ni bases de datos con teléfonos de prospectos.
  Si una fuente los contiene, anonimízala antes de dejarla aquí.

Subcarpetas sugeridas: `make/` (blueprints exportados), `clientes/`, `metricas/`, `articulos/`.
